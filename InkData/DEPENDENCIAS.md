# 📦 DEPENDÊNCIAS ADICIONAIS

## Backend

```powershell
cd backend

# Dependências principais
npm install bcryptjs jsonwebtoken @supabase/supabase-js

# Opcional (se não tiver)
npm install express cors dotenv axios
```

## Descrição:

- **bcryptjs**: Hash seguro de senhas
- **jsonwebtoken**: Autenticação JWT
- **@supabase/supabase-js**: Cliente Supabase
- **express**: Framework web (já deve ter)
- **cors**: CORS middleware (já deve ter)
- **dotenv**: Variáveis de ambiente (já deve ter)
- **axios**: HTTP client (já deve ter)
